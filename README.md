## 🔍 Understanding the technical side

The software uses a local storage method common in web development. This means the file stores your preferences and your interaction history inside your browser's data storage for this specific file. You do not need to set up a database or a server. Everything happens within the browser environment. 

The process follows a simple loop:
1. You input a prompt.
2. The agent analyzes the structure of your text.
3. The model sends a suggested improvement.
4. You rate the suggestion.
5. The model adjusts based on your rating for your next attempt.

This approach ensures you keep control over your prompts while benefiting from the logic of different AI models. The program remains lightweight because it performs all logic within the structure of a single HTML file.
